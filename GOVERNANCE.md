# Governance

Aether is a small compiler project, not a foundation.

- **Maintainers** merge pull requests and cut releases. Listed in AUTHORS.
- **Contributors** send pull requests under CONTRIBUTING.md.
- Language changes require a spec update in `docs/` in the same PR.
- Releases follow SemVer for the library API and the source language.
  Bytecode and LLVM text are exempt and may break at any time.
- There is no trademark on the name “Aether” inside this repository.
