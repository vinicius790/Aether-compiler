# Support

This is an open-source compiler, not a product with an SLA.

- Bugs and miscompilations: GitHub issues, with a reduced `.ae` file.
- Language questions: `docs/language.md` and `docs/grammar.md`.
- Fuzzer questions: `docs/fuzzing.md`.
- Security: `SECURITY.md`.

There is no official Discord, forum or commercial support channel.
